# Windows 登录静默启动（托盘模式）验收

## 行为

设置 → 通用 → 启动行为：
1. 开启「登录时自动启动」：当前用户 HKCU Run 启动项将保存
   `"SayAll.exe" --sayall-login-start`，不需要管理员权限。
2. 开启「开机静默启动（仅托盘）」：Windows 登录自动运行时，即使
   「启动时自动打开主面板」仍为开启，主窗口也不显示、不抢焦点、
   不出现在任务栏，但托盘图标存在，蓝牙、语音和按键功能正常运行。
3. 手动双击程序或快捷方式没有登录启动标记，仍遵守原来
   「启动时自动打开主面板」设置。
4. 点击托盘图标或菜单「显示主界面」恢复；点击「退出」才退出程序。
5. 如果 SayAll 已经运行，Windows 登录启动的第二进程不会强行把主界面弹出；
   手动启动第二进程仍会请求显示现有实例。
6. 关闭「登录时自动启动」后，静默选项暂不可修改、暂不生效；
   重新打开登录自启动时，保留上次选择。旧设置文件中缺少静默选项时默认关闭。

## 实机测试

- 开启登录自启 + 开启静默，保持普通启动显示开关为开启；注销 Windows 再登录，
  确认只有托盘图标，没有主窗口、任务栏按钮或启动时闪窗。
- 托盘左键 /「显示主界面」恢复，窗口应可输入、可连接小米遥控器；
  点击标题栏 X 后再次隐藏到托盘。
- 手动退出后双击桌面快捷方式：窗口应打开（区别于登录自启）。
- 登录自启开启但静默关闭：登录时按原主窗口策略显示。
- 禁用登录自启后重新登录：不应再自动启动；恢复开关后原静默设置仍然保留。
- 更新后首次登录、首次向导未完成：静默登录不抢前台；可从托盘查看更新和继续向导。
- 以 `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v SayAll`
  确认启动命令带登录标记；如安装路径含空格，exe 路径必须加引号。
- Windows CI runtime-simulation 必须继续显示窗口，以免后台 WebView 触发节流。

CI 只验证代码与模拟流程，注销 / 真实开机行为仍须 Windows 真机验收。
